# OnDeviceRAG 0.2.0 — Conversation History and Rename Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans, inline (the author's choice). Per task: pitch (What/Why/How/Alternatives) → "go ahead" → failing test → implementation → passing tests → mutation check → report → commit (no AI attribution). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Two switchable history features — recent user questions in the search query, and the recent turns that fit a token budget returned for the prompt — plus `renameDocument`, released as 0.2.0.

**Architecture:** `ChatTurn` (role + text) replaces `[String]` history. `HistorySettings` in `RAGConfiguration` holds both switches (off by default). The engine passes history to the retriever only when `useForSearch` is on, and runs a new `HistoryWindow` (newest-first, budgeted, stops at the first turn that doesn't fit) only when `includeInContext` is on. Rename re-ingests the stored source.

**Tech Stack:** Swift 6 package (tools 6.4, iOS/macOS 27), Swift Testing, fake embedder + test token counters.

**Spec:** `Docs/0.2.0-history-design.md`

## Global Constraints

- Both switches default **off**; with both off, results must be identical to passing no history.
- Assistant turns are never added to the search query.
- `RAGContext.tokenCount` keeps counting the sections only; history has its own `historyTokenCount`.
- No storage format change (`.ragdoc` / `.ragindex` stay version 1).
- Work on branch `feature/chat-history`; commits use the GitHub noreply identity already configured; no AI attribution.
- Run tests with `swift test` in `~/Developer/OnDeviceRag` (91 tests before this plan; model-gated tests skip if the model is missing).

```swift
/// One message of a conversation, passed as `history` to `RAGEngine.search` / `context(for:)`.
public struct ChatTurn: Sendable, Hashable, Codable {
    public enum Role: String, Sendable, Codable {
        case user
        case assistant
    }

    public var role: Role
    public var text: String

    public init(role: Role, text: String) {
        self.role = role
        self.text = text
    }

    public static func user(_ text: String) -> ChatTurn { ChatTurn(role: .user, text: text) }
    public static func assistant(_ text: String) -> ChatTurn { ChatTurn(role: .assistant, text: text) }

    /// "User: …" / "Assistant: …" — also what `HistoryWindow` counts for this turn.
    func line(userLabel: String = "User", assistantLabel: String = "Assistant") -> String {
        "\(role == .user ? userLabel : assistantLabel): \(text)"
    }

    /// The turns as labeled lines, oldest first, separated by blank lines (ready for a prompt).
    public static func format(_ turns: [ChatTurn], userLabel: String = "User", assistantLabel: String = "Assistant") -> String {
        turns.map { $0.line(userLabel: userLabel, assistantLabel: assistantLabel) }.joined(separator: "\n\n")
    }
}
```

```swift
/// Chooses the conversation turns that go into a prompt: newest first, at most `maximumTurns`,
/// while they fit `tokenBudget`. The first turn that doesn't fit ends the window, so the result is
/// always an unbroken run of the latest turns. Returned oldest first. Turns are never cut.
enum HistoryWindow {
    static func select(_ turns: [ChatTurn], maximumTurns: Int, tokenBudget: Int,
                       counter: any TokenCounter) async -> (turns: [ChatTurn], tokenCount: Int) {
        guard maximumTurns > 0, tokenBudget > 0 else { return ([], 0) }
        var kept: [ChatTurn] = []
        var used = 0
        var separatorCost: Int?
        for turn in turns.reversed().prefix(maximumTurns) {
            var separator = 0
            if !kept.isEmpty {
                if separatorCost == nil { separatorCost = await counter.count("\n\n").value }
                separator = separatorCost ?? 0
            }
            let cost = await counter.count(turn.line()).value
            guard used + separator + cost <= tokenBudget else { break }
            kept.append(turn)
            used += separator + cost
        }
        return (Array(kept.reversed()), used)
    }
}
```
